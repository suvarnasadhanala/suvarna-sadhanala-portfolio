# Suvarna Sadhanala — Portfolio Website

A responsive, motion-rich, light editorial portfolio for a B.Tech Computer Science student interested in software development, AI, cybersecurity, networking, and technology projects. The design is multidisciplinary and intentionally avoids a cyber-themed visual style.

## Run locally
1. Download and extract the ZIP.
2. Open `index.html` in a modern browser.
3. For local development, you can use VS Code with the Live Server extension (optional).

No Docker, backend, or database is required.

## Update your details
- Edit `js/portfolio-data.js` to update skills, projects, internships, email, LinkedIn, and GitHub.
- Your profile photo is stored at `assets/images/suvarna-profile.jpg`. Replace that file with another portrait (keeping the same filename) to update it across the site.
- Add your resume file and create a resume button in `index.html` if you want to publish it.
- Review all dates, internship descriptions, and project features before publishing. Some project details are written as concepts and should be updated to match your actual implementation.

## Publish with GitHub Pages
1. Create a GitHub repository for your portfolio.
2. Upload the contents of this folder (not the ZIP itself).
3. In repository Settings → Pages, select the main branch and root folder.
4. Save and wait for GitHub Pages to publish the site.

## Notes
- Google Fonts are loaded from the web; fallback fonts will be used offline.
- This website does not collect or store contact-form submissions.
- Keep project claims and skill levels accurate. Add repository links only for projects you are ready to share.

## Motion and accessibility
The site includes animated gradients, orbiting artwork, a looping marquee, floating elements, hover effects, and scroll-reveal sections. Animations respect the visitor's reduced-motion system preference.


## Resume download
The main resume PDF is included at `assets/resume/Suvarna_Sadhanala_Resume.pdf`. The website's resume buttons link to this file. Replace that PDF at the same path to update the downloadable resume.

## Content accuracy
Achievements, internships, workshops, certificates, education, and skills are based on the supplied resume. The growth areas section is clearly labelled as suggested self-reflection, not weaknesses stated in the resume; edit it to match your own view.
